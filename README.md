# Typed Task Tracker

Typed data layer, state management and rendering for a task tracker (TypeScript, no UI framework).

## Structure

```
src/        types, validation, api, fetcher, filters, pagination, store, cache, search, render, stats
tests/      one *.test.ts per src module
docs/       design decisions and learning log
.github/    CI workflow and PR template
```

## Scripts

`npm run lint` · `npm run typecheck` · `npm test` · `npm run test:coverage`
